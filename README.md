Внутренний «мета»-репозиторий с правилами и практиками команды: кодстайл, Git/GitHub, ветвление, коммиты, CI/CD и онбординг.

## Технологии команды

- **Python 3.11+** - управление зависимостями строго через **uv**.
- **Web**: React + Vite.
- **Смарт-контракты**: Solidity + Hardhat/Anvil (локальный PoA дев-нет). Используем OpenZeppelin (Ownable, AccessControl).


## CI/CD (обзор)

* **PR → dev**: линт, тесты, сборки (web, backend, contracts compile/test).
* **PR → main**: те же проверки + подготовка релиза (tag, changelog).
* **Deploy**:

  * `dev` - автодеплой в стейджинг.
  * `main` - релиз в прод с ручным подтверждением.
* Любой пайплайн падает → PR не мержим.

## Как спросить/предложить изменения

* Открой issue в этом репозитории (`meta`) с меткой `proposal`.
* В PR добавь краткое обоснование и примеры.
